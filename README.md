# 🔐 Security Projects

## Double Clickjacking Defense

> Double Clickjacking 공격을 분석하고 이를 방어하기 위한 시스템을 구현했습니다.

사용자의 연속적인 클릭 흐름을 악용하여  
의도하지 않은 UI 동작을 유도하는 Double Clickjacking 공격을 분석하고,

사용자의 **Click Flow, User Gesture, Window Focus 및 페이지 상태** 등을 기반으로  
비정상적인 동작을 탐지하고 차단하는 방어 기능을 구현했습니다.

### 주요 구현

- Double Clickjacking 공격 시나리오 분석
- 사용자 Click Flow 분석
- User Gesture 검증
- Window Focus 상태 확인
- 비정상적인 Redirect 탐지
- 강제 Click 동작 탐지
- 악성 다운로드 동작 탐지
- Chrome Extension 기반 방어 시스템 구현
